## Architecture

| Decision          | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Event share links | Mobile share uses the OS share sheet with an HTTPS link to the public web event page (`EXPO_PUBLIC_WEB_URL/events/{id}`). Universal Links (iOS) and App Links (Android) open that URL in the app when installed; otherwise the web page loads. Association files are served from `apps/web` `/.well-known/*` when `APPLE_TEAM_ID` / `ANDROID_SHA256_CERT_FINGERPRINTS` are set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| API style         | REST + OpenAPI (Zod-first via @hono/zod-openapi) for both public and admin APIs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Auth              | Own auth in the APIs, users/devices/sessions in Postgres. No Cognito. App stores a random device credential in secure storage; a user id alone never authenticates. On launch and foreground the app exchanges that credential; if the device or user is gone or banned, a confirmed alert wipes on-device stores and restarts onboarding. A failed network call does not.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Data workers      | Part of the monorepo (`apps/data-workers`); one adapter per source; scheduled Fargate tasks (~0.25 vCPU / 0.5 GB).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Scan chat         | The tool-calling scan uses local Ollama unless `CHAT_PROVIDER` is set. `chatgpt` posts to OpenAI chat completions with `OPENAI_API_KEY` (default model `gpt-4.1-mini`). `claude` posts to Anthropic messages with `ANTHROPIC_API_KEY` (default model `claude-sonnet-5-5`). `runpod` starts one named GPU pod, drains `pending_scan` in batches of five with three scans at a time, and stops the pod when the queue is empty or the run ends. The pod serves `Qwen/Qwen3-32B-AWQ` through vLLM in `CA-MTL-1`, with thinking turned off. A pod started with another model is replaced. Weights stay on a network volume. `EU-SE-1` has the A40 and no network volume, so it cannot keep those weights. A second scan exits while the first holds the database lock. A `chatUrl` still overrides the endpoint for the other providers. `http` is only allowed on loopback. A named provider with no key does not fall back to Ollama. |
| Hosting           | AWS, eu-north-1 (Stockholm), dev/staging/prod accounts, CDK.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| UI kit            | Material UI (`@mui/material` + `@mui/material-nextjs`) on `apps/web` and `apps/admin`. Mobile uses custom RN screens plus `@expo/ui` (universal BottomSheet/etc.) and SwiftUI overlays (`ConfirmationDialog`, `ContextMenu`, `DatePicker`, `Alert`) for system chrome — not React Native Paper / Gluestack.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Monorepo          | pnpm workspaces + Turborepo; Expo (mobile), Next.js (web, admin).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Database          | PostgreSQL + PostGIS on RDS; Drizzle ORM.
